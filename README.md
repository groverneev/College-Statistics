# College Statistics

College Statistics is a data visualization dashboard for exploring and comparing colleges through historical Common Data Set (CDS) information.

**Live site:** [collegestatistics.org](https://collegestatistics.org)

## Features

- Explore admissions trends, including applications, acceptance rates, yield, and early decision statistics.
- Compare SAT and ACT score ranges over time.
- Track tuition, fees, room and board, and financial aid.
- View enrollment and demographic trends.
- See how colleges evaluate academic and nonacademic admissions factors.
- Browse data-driven stories about broader college admissions trends.
- Save schools into Reach, Target, Safety, or Undecided lists.
- Add private notes to individual schools.

## Data

The project uses Common Data Set publications from colleges and universities. Values are source-backed, and unavailable data is left missing rather than estimated.
